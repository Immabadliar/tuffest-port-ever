# Luca portfolio

A minimal static portfolio using the original reference site's HTML, CSS, and JavaScript stack. No dependencies or build step.

Run `npm run dev` and open http://127.0.0.1:5173. Run `npm run check` for JavaScript syntax checks.

Edit `portfolio-data.js` to change the bio, contact links, languages, featured projects, repositories, and experience. Repository entries are a snapshot of the public, non-fork GitHub repositories, so the portfolio does not depend on GitHub API availability at runtime.

Images live in `assets/`. The original supplied kit is retained in `luca_portfolio_kit/`. Screenshots show studio/community context and do not imply authorship of other studio projects. Spong uses the supplied team screenshot. Hiroh and confidential work use text cards because no corresponding project image was supplied.

Deploy by serving the root directory as a static site; no build output is required.
